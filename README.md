# Drum Machine

🔗 [Live Demo](https://drum-machine-one-orcin.vercel.app/) · 💻 [GitHub](https://github.com/Roselineonyeka/drum-machine)

A keyboard-playable drum machine built with React, featuring two switchable sound banks and volume control.

## Features
- ⌨️ Play sounds via keyboard keys or on-screen pads
- 🔊 Two switchable sound banks
- 🎚️ Volume slider
- 🔌 Power toggle

## Tech Stack
- React
- TypeScript
- JavaScript
- HTML/CSS

## Getting Started

```bash
git clone https://github.com/Roselineonyeka/drum-machine.git
cd drum-machine
npm install
npm run dev
```
